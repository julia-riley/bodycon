bodycon Quick Start Guide

Julia Riley & Fonti Kar

2026-09-29

bodycon is an R package for calculating commonly-used body condition indices in wildlife ecology research. In this research field, an individual’s fitness traits, like reproduction and survival, are important measures of individual health and performance. Yet, direct fitness measures like these can be impractical to collect in the field due to financial or logistical research constraints. So, in these cases, animal ecologists often rely on proxies of individual fitness, such as body condition. In general, individuals in better body condition (that are also assumed to have greater energy reserves) experience higher survival and reproductive success than individuals in inferior body condition. This impact of body condition on fitness parameters has been documented across a diversity of taxa. One widely used method of estimating body condition is to relate body mass to a linear measure of body size, but this can be calculated in a variety of ways. This R package contains functions for commonly-used methods of calculation of body condition indices; and we hope to continue to develop this R package to expand the taxa it can be applied to moving forward.

Package Datasets

There are two datasets included in the bodycon R package. The first contains data on the morphology of 46 Maritime Gartersnakes (Thamnophis sirtalis pallidulus) collected in summer of 2022 in New Brunswick and Nova Scotia, Canada. The length measure is snout-vent length (mm), which is the distance from the snake’s snout to the anterior edge of their cloaca. The weight measure is mass (g).

Calculation of body condition indexes

There is one function bciin this R package you can use to calculate the body condition of animals. You can specify the method used to calculate body condition within this function. There are three possible methods. All rely on a standardized length measurement (i.e., tarsus length for birds or snout-vent-length for reptiles) and a measure of weight.

1) Body condition index estimation using residuals from an OLS regression

This example calculates body condition indices from the residuals of an ordinary least squares regression (OLS). This is a traditional approach in ecology as outlined by Krebs and Singleton (1993). The method to specify for this is "resid_ols" and please see the examples below of using it to calculate body condition of gartersnakes:


bci_resid_ols(gartersnake, svl_mm, mass_g)

The default for the bci_resid_ols function is assuming an allometric relationship between animal body size and weight, which is typical for most species (i.e., both are log-transformed before the OLS regression is run). But you can call on the relation = "linear" argument to assume a linear relationship between body size and weight (i.e., these variables would then not be log-transformed).

Scaled mass body condition index (SMI) estimation

Yet, calculating body condition indices from the residuals of an ordinary least squares regression (OLS) has been critiqued in the literature. There is discussion about whether it is the most robust approach (Schulte-Hostedde et al., 2005; Peig and Green, 2009), how its appropriateness may vary by taxon (Jakob et al., 1996; Băncilă et al., 2010; Labocha and Hayes, 2012), and whether it fits the assumptions of certain statistical tests (García-Berthou, 2001). An alternative is the scaled mass index (SMI method) described by Peig and Green (2009), which can be estimated using either OLS or robust regression (as described in this code by Chen-Pan Liao). For SMI, body size and mass are always log-transformed because this method assumes an allometric relationship between the variables.

With OLS regression

Below is an example of using the SMI method’s function using the ordinary least squares (OLS) regression in its estimation of the body condition indices for salamanders. Yet, this method is sensitive to the presence of outliers (i.e., data points that may distort the expected relationship between body length and weight), and so SMI estimation using robust regression (see function bci_smi_rob) may be more appropriate in cases where outliers are present.

Visual comparison of body condition indices

To explore the body condition methods that are most appropriate for your data, you may want to plot the estimations with your observed, raw data to visually compare methods. Of course, please also consider current literature about these BCI estimators to assess whether it is correct for your dataset or the analyses you are planning to apply to them. We will plot BCI estimators for animals using the plot_bci() function from the bodycon package. The plot allows comparison between:

  • OLS residuals (resid_ols)
  • Scaled Mass Index using ordinary least squares regression (smi_ols)
  • Scaled Mass Index using robust regression (smi_rob)

Additionally, raw data points can be grouped (e.g., by sex or population) and colours can be customized for both raw points and method lines. In the following examples we will use the gartersnakes dataset, which has previously been outlined above.

Basic Plot

An example of a simple plot of all three BCI methods with default colours.

plot_bci(
   gartersnake,
   svl_mm,
   mass_g,
   method = c("resid_ols", "smi_ols", "smi_rob")
   )

This is another basic plot, that is comparing the linear vs. allometric relationship between body size and weight variables. This would be worthwhile to visually examine before you decide not to go with the most common approach for calculation of a residual body condition index, which is an allometric relationship.

plot_bci(
   gartersnake,
   svl_mm,
   mass_g,
   method = c("resid_ols"),
   relation = c("linear", "allometric")
   )

Grouped plot

You can highlight different groups in the raw data using the group argument. For example, here we separate male and female gartersnakes and the fit of the SMI method using robust regression:

plot_bci(
   gartersnake,
   svl_mm,
   mass_g,
   method = c("smi_rob"),
   group = sex
   )

Custom colours and a hidden legend

You can further adjust your plot with custom colours for the observed data groups, the methods lines, and adjust whether or not there is a legend:

plot_bci(
   gartersnake,
   svl_mm,
   mass_g,
   method = c("smi_rob"),
   group = sex,
   group_colours = c("M" = "darkorange3", "F" = "darkorchid"),
   method_colours = c("SMI (robust)" = "black")
)

You can also adjust the labels, presence of a legend, and, in addition to plotting the graph, return the preductions so you can customise a figure further on your own. Check our the documentation for this function using ?plot_bci for details on all possibel arguments.
