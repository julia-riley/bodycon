# Changelog

## bodycon 0.2.0

*Renamed bci_smi_ols() to bci_smi() to reflect that the scaled mass
index (SMI) uses standardized major axis (SMA) regression to estimate
the scaling exponent.* Updated bci_smi_rob() to use robust standardized
major axis (SMA) regression to estimate the SMI scaling exponent.
*Updated bci() and plot_bci() to use the revised SMI method names and
terminology.* Improved handling of missing values in OLS residual
calculations.

## bodycon 0.1.0

- Initial public release.
